# Shell y portabilidad

1. **`timeout` no existe en macOS** — un script que lo usa falla en la Mac del usuario aunque pase en Linux; lanza el proceso en segundo plano o usa un tope propio. <!-- disparadores: frases=el script usa timeout y falla en la Mac | command not found timeout en macOS | quiero poner un tope de tiempo a un comando | voy a usar timeout para limitar un proceso | funciona en Linux pero no en mi laptop | el adversario no arranca en la Mac porque falta un comando; cmd=timeout -->
2. **`sed -i` no es igual en BSD y GNU** — en macOS necesita un argumento de sufijo (`sed -i ''`); en Linux no lo acepta separado. <!-- disparadores: frases=voy a editar un archivo en sitio con sed | sed -i da error en macOS | el sed funciona en Linux y falla en la Mac | sed dice invalid command code o extra characters | estoy reemplazando texto en un archivo desde un script | ¿cómo uso sed -i en BSD y GNU?; cmd=sed -->
3. **`bc` no está en el Git Bash de Windows** — la aritmética de punto flotante en un test rompe solo en windows-latest. <!-- disparadores: frases=mi test usa bc para sacar un promedio y falla en windows-latest | el CI de Windows dice bc command not found | voy a hacer aritmética con decimales en un script bash del test | estoy calculando porcentajes con bc dentro del workflow de GitHub Actions | pasa en Mac y Linux pero rompe solo en el runner de Windows | cómo sumo números flotantes en bash de forma portable; cmd=bc -->
4. **Windows ignora el `TZ` que le pases desde Git Bash** — ni nombres IANA ni reglas POSIX; un test que depende del huso da otro resultado. <!-- disparadores: frases=mi test depende de la zona horaria y da otra hora en Windows | estoy poniendo TZ en el script para fijar el huso horario | voy a exportar TZ America/Mexico_City antes de correr el test | el test de fechas pasa en Linux y falla en windows-latest | Git Bash ignora la variable de timezone que le paso | hice un test con la hora local y el resultado cambió -->
5. **Un glob sin coincidencias aborta el script con nullglob o queda literal sin él** — no uses globs en snippets que un agente copia y ejecuta. <!-- disparadores: frases=voy a poner un for sobre *.json en un snippet que va a copiar otro agente | el for con *.md corre una vez con el texto literal | estoy usando nullglob y el script aborta cuando no hay archivos | escribiendo un ejemplo de bash con wildcard para que otro agente lo ejecute | el glob no encontró nada y el loop corrió con el patrón literal | quiero iterar sobre ficheros que a veces no existen -->
6. **Git Bash convierte a rutas de Windows los argumentos y variables, no el texto dentro de un JSON** — una ruta `/tmp/...` escrita dentro de un JSON no la encuentra el python de Windows. <!-- disparadores: frases=le paso a python una ruta /tmp dentro de un JSON y no la encuentra en Windows | FileNotFoundError en Windows con una ruta que sí existe en Git Bash | voy a armar un JSON con rutas temporales desde bash para un script python | estoy generando un payload con mktemp y python de Windows no abre el archivo | el argumento se convierte bien pero la ruta dentro del JSON no | la conversión de rutas de MSYS no toca el texto dentro de las comillas del JSON -->
7. **`chmod 000` no impide leer en Windows** — un test que simula un fichero ilegible así pasa en Unix y falla en Windows. <!-- disparadores: frases=voy a simular un archivo ilegible con chmod 000 en un test | el test de permiso denegado pasa en Mac pero falla en Windows | quiero probar el manejo de error al leer un fichero sin permisos | hice chmod 000 y aun así el script pudo leer el archivo | cómo creo un archivo que no se pueda leer para un test portable | estoy testeando PermissionError en windows-latest; cmd=chmod -->
8. **Python en Windows escribe en la página de códigos local, no en UTF-8** — fuerza `reconfigure(encoding="utf-8")` en stdout y stderr de cada script. <!-- disparadores: frases=mi script de Python imprime acentos rotos en Windows | UnicodeEncodeError al hacer print en la consola de Windows con cp1252 | voy a escribir un script Python que imprime en stdout con tildes y eñes | estoy imprimiendo acentos desde python en el runner de Windows | salen signos raros en lugar de la ñ en la salida del script | configuro stdout y stderr de python para que usen utf-8 -->
9. **`open()` sin `encoding` usa la codificación local** — en Windows rompe con acentos; ponlo siempre, también en los tests. <!-- disparadores: frases=voy a leer un archivo con open en Python dentro de un test | estoy abriendo un fichero de texto con open() sin pasar encoding | el test lee un markdown con acentos y revienta en Windows | UnicodeDecodeError charmap codec can't decode byte al leer un archivo | escribí un archivo con write_text y salió con otra codificación | cómo abro y leo un fichero UTF-8 en Python de forma portable -->
10. **Un `while pgrep -f patrón` por SSH no termina nunca** — el propio ssh lleva el patrón en su línea de comandos y se encuentra a sí mismo. <!-- disparadores: frases=espero por SSH a que termine un proceso remoto con pgrep en un while | el loop de espera nunca termina aunque el proceso ya acabó | voy a hacer polling del proceso en el servidor con pgrep -f | estoy esperando que acabe un job en el VPS y se queda colgado | pgrep se encuentra a sí mismo y el while sigue girando | monitoreo un proceso remoto vía ssh hasta que desaparezca; cmd=pgrep, ssh -->
11. **Un heredoc con comillas simples desbalanceadas rompe el bloque entero en silencio** — un apóstrofe dentro de un texto en inglés basta. <!-- disparadores: frases=voy a escribir un heredoc con un texto en inglés que lleva apóstrofes | el comando bash con cat y EOF se rompe sin mensaje de error | estoy pasando un bloque de texto multilínea a un archivo desde bash | salió un error de comilla sin cerrar en un heredoc | hice un here-doc con don't dentro y todo el bloque quedó mal | unexpected EOF while looking for matching quote en mi comando -->
12. **`set -e` no salta dentro de una condición** — un comando que falla dentro de un `if` o de un `&&` no detiene el script. <!-- disparadores: frases=puse set -e pero el script siguió aunque un comando falló | estoy usando un if o un && con un comando que puede fallar | quiero que el script se detenga ante cualquier error en bash | por qué no aborta el script si el comando falla dentro de un if | voy a encadenar comandos con && y confío en set -e | el errexit no funciona cuando el fallo está en una condición; cmd=set -->
13. **Los permisos de ejecución no viajan igual en todos los checkouts** — invoca los scripts con `bash script.sh`, no con `./script.sh`. <!-- disparadores: frases=voy a llamar un script con ./script.sh en el workflow | da permission denied al ejecutar el script en el CI | el script no tiene bit de ejecución después del checkout | estoy escribiendo el hook que invoca un .sh del repo | hice chmod +x pero en otro clon ya no lo tiene | cómo ejecuto un shell script sin depender del permiso de ejecución; cmd=bash; path=*.sh -->
14. **`echo -e` no es portable** — usa `printf` para secuencias de escape. <!-- disparadores: frases=voy a imprimir un salto de línea con echo -e en un script | el echo -e muestra el texto -e literal en macOS | estoy usando echo con barra n y los saltos de línea no salen | quiero imprimir tabuladores y colores ANSI desde bash | la salida del echo sale distinta en sh y en bash | cómo imprimo secuencias de escape de forma portable; cmd=echo -->
15. **`readlink -f` no existe en el macOS antiguo** — resuelve rutas con `cd "$(dirname ...)" && pwd`. <!-- disparadores: frases=voy a resolver la ruta absoluta del script con readlink -f | readlink da illegal option en la Mac | estoy sacando el directorio del script para hacer cd a su carpeta | cómo obtengo la ruta real de un symlink en macOS viejo | el script funciona en Linux pero en Mac no resuelve la ruta | calculo SCRIPT_DIR al inicio del script bash; cmd=readlink -->
16. **Una variable sin comillas se parte en los espacios** — una ruta con espacios llega como dos argumentos. <!-- disparadores: frases=la ruta tiene espacios y el comando recibe dos argumentos | voy a usar una variable de bash en un cp o rm sin comillas | estoy iterando archivos con nombres que llevan espacios | No such file or directory porque el path se partió por el espacio | escribí rm con una variable y borró algo que no debía | cómo paso una variable con espacios como un solo argumento -->
17. **En la Mac no hay `timeout`: el comando del adversario falla al arrancar** — lanzarlo en segundo plano con su propio tope. <!-- disparadores: frases=voy a lanzar al adversario con timeout para ponerle tope de tiempo | timeout command not found en la Mac | el comando del adversario falla al arrancar y no sale nada | estoy corriendo el verificador en segundo plano y quiero un límite de tiempo | cómo pongo un tope de duración a un proceso en macOS | lancé el adversario y murió de inmediato sin salida; cmd=timeout; tool=Bash -->
